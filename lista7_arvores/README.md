# Lista 7 — Árvores binárias

Implementação em C dos 14 exercícios de árvores da disciplina AED I (UFPel).

Cada exercício está em `exercicioNN.c`; `arvore.h` reúne as funções, `main.c` demonstra os resultados e `tests/testar_arvore.c` verifica os casos principais.

## Executar

```sh
make
./programa
make test
make clean
```

Convenções: altura de árvore vazia = -1; árvore vazia é considerada cheia, perfeita e completa. O exercício 14 pressupõe valores únicos para identificar os nós.
