## Compilar e testar

É necessário ter GCC e Make instalados.

```sh
make test
```

Para executar uma lista individualmente, entre na pasta correspondente. Exemplo:

```sh
cd lista7_arvores
make
./programa
```

Cada pasta contém os arquivos dos exercícios e, quando necessário, seu próprio Makefile.
